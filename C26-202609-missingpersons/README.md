# GeoAI-MissingPersons-Peru — moved

This folder was the pre-standardization home of the C26 project. **Its content
was migrated to [`papers/c26-2026/`](../papers/c26-2026/) on 2026-10-02**, which
now holds the data, code, results, tests, notebook and manuscript:

| What | Where |
|---|---|
| Manuscript (`main.qmd`, references, figures) | [`papers/c26-2026/paper/`](../papers/c26-2026/paper/) |
| Input data | [`papers/c26-2026/data/`](../papers/c26-2026/data/) |
| Analysis code and frozen plan | [`papers/c26-2026/experiments/`](../papers/c26-2026/experiments/) |
| Results (JSON, tables, figures) | [`papers/c26-2026/outputs/`](../papers/c26-2026/outputs/) |
| Tests, notebook, original DOCX/PDF | `papers/c26-2026/tests/`, `notebooks/`, `legacy/` |

The article is:

> M. Evangelista Gamarra, E.A. Alama Carreño, P.E. Figueroa Rosas. *A
> reproducible GeoAI framework for explainable spatiotemporal analysis of
> national missing-person registers: multi-algorithm clustering and multilevel
> validation (Peru, 2019–2025).* Submitted to *Information Sciences*.

The reproducibility package is archived in Zenodo:
[10.5281/zenodo.23066963](https://doi.org/10.5281/zenodo.23066963).
