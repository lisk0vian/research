#### Data Note

Data Notes concisely describe sound research data with the aim of increasing visibility and transparency, supporting the reuse of research data and helping authors to comply with funder mandates on data sharing.

Authors must use the [Data Note template](https://media.springer.com/full/springer-instructions-for-authors-assets/docx/Data-note-template-Discover.docx). Please follow the instructions in the template, ensure that your data have been deposited in an appropriate [data repository](https://www.springernature.com/gp/authors/research-data-policy/recommended-repositories), and complete table 1 including information on data file formats and data identifiers. Multiple related datasets can be described in a single Data Note if those datasets link to a common research project or share samples or study subjects.
